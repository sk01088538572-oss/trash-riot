# TRASH RIOT 홈페이지

## 폴더 구성
- index.html : 홈페이지
- style.css : 디자인
- script.js : 다운로드/스크롤 효과
- assets/ : 업로드한 이미지
- game/ : 실제 게임 ZIP 파일을 넣는 곳

## 게임 파일 넣기
Unity Windows Build 폴더 전체를 ZIP으로 압축한 뒤 아래 이름으로 저장하세요.

game/TrashRiot-Windows.zip

## 로컬에서 확인
index.html을 더블클릭해서 열어도 대부분의 디자인은 확인할 수 있습니다.
다운로드 버튼은 웹 서버에서 확인하는 것을 권장합니다.

## 수정하면 좋은 부분
- index.html의 TEAM 부분에 팀원 이름/역할 추가
- TRAILER 부분에 YouTube 영상 임베드 추가
- 게임 ZIP 업로드 후 DOWNLOAD 버튼 확인

## 무료 배포
가장 간단한 방법은 GitHub Pages로 이 폴더를 웹사이트로 공개하고,
게임 파일이 큰 경우 itch.io에 게임을 업로드한 뒤 홈페이지의 PLAY NOW를 itch.io 페이지로 연결하는 방식입니다.
